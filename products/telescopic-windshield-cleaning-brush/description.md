# Telescopic Windshield Cleaning Tool with 4 Washable Pads

Cleaning the inside of a sloped windscreen is awkward. This tool extends so you can reach the corners without leaning over the dashboard.

## Features
- Extendable aluminium handle with soft EVA grip
- Triangular pivoting head reaches corners
- 4 washable, reusable cloth pads
- Works on mirrors, windows and shower glass too

## Use
Spray glass cleaner on the pad (cleaner not included), wipe, then wash the pad.
